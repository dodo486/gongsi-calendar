# 배당금 예측 — 공부 노트

배당금 예측 로직을 정하기 전에 업계 방식과 실제 사례를 같이 보며 정리하는 곳. 결론이 나면 `배당예측-워크플로우.md`로 옮긴다.

## 1. 지금 코드 (2026-11-20)

`derive/dividend/amount.py` — 신호 두 개를 고정 순서로 고른다.

| 신호 | 계산 |
|---|---|
| 직전 반복 | 같은 종류 직전 정기 회차 금액, 그 뒤 분할·병합 보정 |
| 컨센 잔여 | 네이버 연간 주당배당금 컨센 − 올해 이미 정한 배당, 남은 회차 수로 나눔 (12월 결산만) |

과거 356회차 검증 (직전 반복):

| 배당종류 | 같음 | ±20% | 오차 중앙값 |
|---|---|---|---|
| 분기배당 | 56% | 78% | 0% |
| 중간배당 | 54% | 79% | 0% |
| 결산배당 | 24% | 53% | 19.6% |

컨센은 2026-11-20부터 쌓기 시작해 과거 검증이 없다.

날짜 로직과 달리 회사 판정·구분·근거 단계가 없다. 우선순위도 적중률이 아니라 고정.

## 2. 업계 방식 (Claude 지식 기준, 원문 확인 전)

| 방식 | 내용 | 확신 |
|---|---|---|
| 정책 우선 | 회사가 숫자로 밝힌 주주환원 정책이 있으면 그걸로 계산 | 높음 |
| 확신도 표시 | 배당 예측 업체는 종목마다 사람이 판단하고 확신도(높음·중간·낮음)를 붙임 — 우리 날짜 "구분"과 같은 생각 | 높음 |
| 지수배당 | 확정분 + 종목별 예측(컨센·자체 추정)의 합 — 우리 지수배당포인트와 같은 구조 | 높음 |
| EPS × 배당성향 | 애널리스트 모델의 한 줄. 어떤 회사에 맞는지 판단이 핵심 | 중간 |
| 린트너 모형 | 배당이 목표(배당성향 × EPS) 쪽으로 천천히 따라간다는 학계 모형. 실무에서 종목별 회귀로 쓰는 표준은 아님 | 중간 |

핵심: 공식 하나가 아니라 **회사가 배당을 정하는 방식을 먼저 알아내고 그 방식대로 계산**. 날짜에서 정관으로 고정·유동을 먼저 판정한 것과 같은 구조.

## 3. 사례 — 삼성전자 2026 결산배당

**사실** (저장소)
- 2026년 이미 정한 배당: 1분기 372 · 2분기 374 · 3분기 4,601(특별 섞임) = 5,347원
- 2026 순이익 약 294조 (1~3분기 194조 + 4분기 컨센 100조), 66.6억 주 → EPS 약 44,200원
- 네이버 2026 연간 주당배당금 컨센 9,433원
- OpenDART 2020~2025: 주당배당금 1,444원 근처 고정, 배당성향 17.9~78%
- 정책: 3년 단위 주주환원 정책(2024~2026) — 정규배당 연 9.8조 + 3년 FCF 50% 환원

**정책 계산** (FCF = 영업현금흐름 − 유형·무형자산 취득)

| 항목 | 금액 |
|---|---|
| FCF 2024 / 2025 / 2026 1~3분기 | 19.2조 / 33.2조 / 183.3조 |
| 3년 FCF의 50% (4분기 빼고 / 1~3분기 평균으로 넣고) | 117.9조 / 148.4조 |
| 이미 쓴 것 (2024~2025 환원 + 2026 정규 + 3분기 특별분) | 67.3조 |
| 2026 자사주 매입 (전부 임직원 보상용) | 28.25조 |

| 가정 | 남은 재원 | 결산배당 (정규 374원 포함) |
|---|---|---|
| 보상용 매입은 환원 아님 | 50.6 ~ 81.1조 | 7,970 ~ 12,550원 |
| 보상용 매입도 환원으로 침 | 22.3 ~ 52.9조 | 3,720 ~ 8,320원 |

**방식별 결과**

| 방식 | 결산배당 | 판단 |
|---|---|---|
| 정규배당만 | 374원 | 확실한 최소 |
| 직전 반복 | 376 ~ 566원 | 남은 재원을 못 봄 |
| 린트너 | 376 ~ 1,340원 | 안 맞음 — 다섯 점으로 맞춘 값이라 2020 특별배당 하나로 속도가 0.64↔0.01 |
| EPS × 배당성향 | 5,747 ~ 6,587원 | 범위 안이지만 우연 — 과거 배당성향은 이익이 작을 때 높게 나온 결과값 |
| **컨센 잔여** | **4,086원** | 되돌리면 남은 재원 24.7조 ≈ "보상용도 환원 · 4분기 FCF 빼고" 22.3조 — 정책 계산과 독립적으로 일치 |

**결론**: 최소 374원 · 가장 그럴듯한 값 약 4,086원 · 위쪽 8,320원 (회사가 보상용 매입을 환원에서 빼면 12,550원)

**배운 것**
- 삼성은 정책형. 회사 판정이 먼저고, 정책형이면 린트너·배당성향 신호는 쓰지 않는다.
- 정책형은 "최소(정규) + 범위(정책 잔여) + 가운데(컨센)"로 보여 준다.
- 정책 잔여에는 FCF(현금흐름)와 자사주 매입 목적(소각·보상)이 필요하다 — 둘 다 저장소에 아직 없음.
