# 배당 예측 설계 — 2부: 배당금(DPS) 예측 (공시 기반)

> 1부(`배당예측-워크플로우.md`)는 **기준일 하나 맞히기**였다. 2부는 **주당배당금(DPS) 맞히기**다.
> 전제·소스·검증 방식은 1부와 공유하되, 성격이 다르다 — **날짜는 분류, 금액은 추정.**
> 기초(금액을 정하는 구조·종류별 성격·회사 유형)를 공시로 정의한 뒤, 금액 예측 워크플로우로 묶는다.
> 공부 노트 `배당금-예측-공부.md`의 결론(백테스트·삼성 사례)을 여기로 옮겨 정본화한다.

---

## 0. 1부와의 관계 — 날짜가 금액의 골격

- 금액 예측은 **회차(= 종목 × 분기)** 단위. 회차 식별·결산월(`acc_mt`)·분할/병합 주식수 보정은 **1부가 이미 푼다.** 2부는 "그 회차에 얼마"만 더한다.
- **금액은 날짜를 바꾸지 않는다** — 특별·주식배당은 모회차 기준일에 귀속(1부 §4.1). 2부는 날짜 레이어 위에 금액 레이어를 얹는 구조.
- 출력은 1부와 같은 자리(캘린더 배당 클릭 상세 · 지수배당포인트 · 엑셀). 금액은 **단일 값이 아니라 "최소 / 중앙 / 범위 + 출처 단계"**로 낸다(§5.4).

## 1. 배당금의 성격 — 왜 "분류"가 아니라 "추정"인가

| | 날짜(기준일, 1부) | 금액(DPS, 2부) |
|---|---|---|
| 정하는 주체 | **법·정관**이 제약 | **회사 재량**(이익 × 정책) |
| 후보 공간 | 결산기말·분기말·이사회 지정일 — **이산·좁음** | 0원 ~ 배당가능이익 — **연속** |
| 문제 유형 | 분류(고정/유동) | **회귀(추정)** |
| 법의 역할 | 날짜를 못박음 | **상한만** 정함(배당가능이익) |
| 평가 | 맞다/틀리다 | **오차 %** (같음·±20%·오차 중앙값) |

→ 금액은 본질적으로 추정이므로, 1부의 "구분(grade)"에 대응하는 건 **회사 유형(§3) + 확신도**다. 공식 하나로 전 종목을 맞히려 하지 말고, **회사가 배당을 정하는 방식을 먼저 판정하고 그 방식대로 계산**한다(날짜에서 정관으로 고정/유동을 먼저 가른 것과 같은 구조).

### 1.1. 금액을 정하는 3층 구조

회사가 배당금을 정할 땐 항상 이 세 층을 거친다. **금액 예측 = 세 층을 각각 공시로 메우는 일.**

```
① 재원 (얼마나 줄 수 있나) ──── 배당가능이익 = 법적 상한 (상법 §462)
② 정책 (얼마를 주기로 하나) ─── 배당성향·최소DPS·총환원율·FCF% = 회사가 공시로 공개하는 "가이드"
③ 실적 (올해 얼마 벌었나) ───── 당기순이익 (잠정실적·컨센서스)

   총배당 = ② × ③
   DPS   = 총배당 ÷ (발행주식 − 자기주식)      ← 증자 신주 배당기산일·자사주 소각 보정
   체크   = DPS ≤ ① 배당가능이익               ← 물리적 상한 초과 여부만
```

- **진짜 동력은 ② × ③**(배당성향 × 순이익). **①배당가능이익(잔여이익)은 거의 바인딩되지 않는다** — 대형주는 이익 대비 배당이 작아서. ①은 "예측값이 물리적으로 가능한가"를 거르는 **경계**로만 쓴다.
- 날짜 로직에 "공시 → judge() → 기준일" 파이프라인이 있었듯, 금액은 **"공시(성향·순이익·정책) → 배분 계산 → DPS"** 파이프라인이 필요하다. 현 코드엔 이 **배분 계산 단계가 비어** 있다(§7).

### 1.2. ① 배당가능이익 (상법 §462) — 상한의 정확한 정의

```
배당가능이익 = 순자산 − 자본금 − (적립된 자본준비금 + 이익준비금) − 당기 적립 예정 이익준비금 − 미실현이익
```
- **이익준비금(상법 §458):** 현금배당액의 1/10 이상을 자본금의 1/2에 달할 때까지 매 결산기 적립 → 배당을 늘리면 상한이 미세하게 깎인다(대개 한도 소진돼 영향 없음).
- **주의: 재원은 별도(개별)재무제표 기준.** 반면 공시 지표의 "배당성향"은 **연결** 기준으로 적힌 경우가 많다(`dart_alot` = (연결)현금배당성향). → 성향 × **연결**순이익으로 총배당을 추정하되, 상한 체크는 **별도** 배당가능이익으로. 섞지 말 것.

## 2. 배당 종류별 금액 성격 + 회사 가이드

종류마다 금액의 **성격**이 다르고, 따라서 읽어야 할 공시가 다르다. (종류의 법적 근거·날짜 성격은 1부 §1 참조)

| 종류 | 금액 성격 | 회사가 미리 주는 가이드(신호) | 백테스트(직전 반복) |
|---|---|---|---|
| **결산배당** | 연 1회, 최대, **실적 연동 변동분** | 목표 배당성향 / 최소 DPS / "전년 이상" / 총환원율 | 같음 24% · ±20% 53% · 오차중앙 **19.6%** ← 어려움 |
| **분기·중간배당** | **정액 성향 강함**(매 분기 유사) | "분기 OOO원 균등" 또는 연 목표를 4분할 | 분기 같음 56%·±20% 78% / 중간 54%·79% · 오차중앙 **0%** ← 직전 반복이 꽤 맞음 |
| **특별배당** | **일회성**(자산매각·초과이익) | 거의 없음 ("초과이익 환원" 정도) | — **예측에서 분리**(`SPECIAL_MULT=2`) |
| **주식배당** | 금액 아님 — **주식 수**(1주당 N주) | 드물게 "주식배당 병행" 선언 | 별도 절차 |

**설계 함의 (데이터로 뒷받침):**
- **분기·중간배당 = 직전 회차 반복 베이스로 충분**(오차 중앙 0%). 여기에 공들일 필요 적음. 균등배당이 깨지는 건 연말 조정·정책 변경 때뿐.
- **결산배당이 전장**(오차 중앙 19.6%). 2부의 모델링 역량은 **결산배당에 집중**한다 — 정책 × 순이익이 필요한 곳.
- 특별배당을 정기배당에 섞으면 과대추정(작년 특별 포함 금액 반복). 종류 분리가 금액 정확도의 전제.

## 3. 회사 환원 스타일 — 금액 판정의 핵심(= 날짜의 "구분"에 대응)

같은 결산배당이라도 회사가 **어떤 원칙으로 금액을 정하는지**가 다르다. 이 스타일을 공시로 판정하면 "어떤 신호를 쓸지"가 결정된다. **밸류업·배당정책 공시 문장을 네 유형으로 분류하는 게 2부의 1차 작업.**

| 스타일 | 회사 선언 예시 | 예측 동력 | 쓰는 신호 | 안 쓰는 신호 |
|---|---|---|---|---|
| **이익연동형**(성향 고정) | "별도 순이익의 30%" | **순이익** 예측 | 순이익(M5) × 목표성향(M2·M3) | 린트너·과거 DPS |
| **DPS 안정형**(정액·점증) | "주당 최소 OOO원, 전년 이상" | 작년 DPS = 바닥, 실적은 상방만 | 과거 DPS 추세(M7)·직전 반복(M13) | 성향×이익 |
| **총주주환원율형** | "순이익의 50%를 **배당+자사주**로" | 환원총액 − **자사주 매입액** = 배당 몫 | 밸류업(M3) − 자사주(M9) | 단순 성향 |
| **FCF 연동형** | "**잉여현금흐름의 OO%**" | FCF 추정 | 현금흐름(M8 재원)·배당정책(M2) | EPS×성향 |

- **판정 우선순위(안):** 밸류업·배당정책 공시에 **숫자(성향%·최소DPS·환원율·FCF%)가 명시**된 회사 = 정책형(위 네 유형 중 선언대로). 숫자 선언이 없고 **과거 DPS가 몇 년째 정액** = 안정형. 둘 다 없고 **배당성향이 들쭉날쭉** = 이익연동형(과거 평균 성향 적용). 이력도 정책도 없음 = **근거 약함**(직전 반복 또는 미정).
- **총주주환원율형이 함정:** 환원율이 높아도 그 해 자사주 매입이 크면 현금배당은 **줄 수 있다.** 자사주 취득·소각 공시(`capital.py`가 이미 수집)를 안 보면 틀린다 — 날짜엔 없던, 금액 특유의 교차검증.
- **정책형은 단일 값이 아니라 범위로:** 최소(정규·확정분) / 중앙(컨센 또는 정책 중앙) / 상단(정책 잔여 전액). 삼성 사례(§6.2)가 전형.

## 5. 배당금 예측 워크플로우 (통합 본문)

> **대전제:** 금액 예측 = [종목 × 결산배당 회차]에서 **DPS 하나를 추정.** 분기·중간은 직전 반복 베이스(§2). 아래는 결산배당 중심 end-to-end.

### 5.1. 회사 유형 판정 (§3)
밸류업·배당정책 공시의 숫자 선언 → 이익연동 / 안정형 / 총환원율 / FCF / 근거약함 중 하나. 판정 근거(공시 날짜·링크·문장)를 `style`·`style_src`로 싣는다. (날짜의 `grade`·`case`와 같은 발상)

### 5.2. 신호 수집 (M1~M13)
확정(M1) 있으면 종료. 없으면 유형이 지정한 신호만 모은다.
- 이익연동 → 순이익(M5, 없으면 분기 누적) × 목표성향(M2·M3, 없으면 M7 3개년 평균성향)
- 안정형 → 과거 DPS 추세(M7)·직전 반복(M13), 작년 DPS를 바닥으로
- 총환원율 → 환원총액(M3) − 자사주 매입액(M9) = 배당 몫
- FCF → FCF(현금흐름) × 환원율(M2) − 자사주(M9)
- 근거약함 → 직전 반복(M13) 또는 컨센(M12)

### 5.3. 배분 계산 → 주식수 보정 → 상한 체크
```
총배당 = (유형별 동력)
DPS   = 총배당 ÷ (발행주식 − 자기주식)       ← 증자 신주 배당기산일(M10)·자사주 소각(M9) 반영
       − (총환원율 회사면 현금배당 몫만)
sanity: DPS ≤ 배당가능이익/주식수 (M8)        ← 넘으면 경고
```

### 5.4. 산출물 — 단일 값이 아니라 범위
- **최소** = 확정·정규분(이미 정해진 분기배당 합 등) — 깔아두는 바닥.
- **중앙** = 가장 그럴듯한 값(유형별 메인 신호 / 컨센).
- **상단** = 정책 잔여 전액 가정.
- 각 값에 **출처 단계**(M번호·공시 날짜·링크) 명시. 확신도(높음/중간/낮음)는 유형·신호 수로.
- 지수배당포인트(`divpoints`)엔 **중앙값**을 쓰되, 확정분과 예측분을 색/플래그로 분리(1부 §3 월물 리스크와 동일 원칙).

### 5.5. 법·제도 경계 (틀릴 수 없는 범위)
- DPS × 주식수 ≤ 배당가능이익(M8). 초과면 불가·경고.
- 배당성향 음수/비정상(적자에 고배당) → 재원·특별사유 경고.
- 2027~ 지배구조보고서 사전공개가 뜬 회차는 **그 값으로 확정**(M4).

## 6. 검증 — 사람이 확인하는 법

### 6.1. 백테스트 지표 (`amount` --verify, 1부 verify와 동형)
지난 회차를 그 회차 확정 공시 **직전 시점**에서 다시 추정해 실제 DPS와 비교.

| 지표 | 정의 |
|---|---|
| **같음 %** | 예측 = 실제 (정액배당 종목) |
| **±20% 적중** | \|예측 − 실제\| / 실제 ≤ 20% |
| **오차 중앙값** | median(\|예측 − 실제\| / 실제) |
| 신호별 적중률 | M별로 따로 — **우선순위를 이 숫자로 정한다**(현재는 고정 순서) |
| 유형별 내역 | §3 유형별 회차 수·오차 — 어디에 공들일지 |

**현 베이스라인(직전 반복, 356회차):** 분기 56%/78%, 중간 54%/79%, 결산 **24%/53%/오차중앙 19.6%**. → 2부의 목표는 **결산배당 오차 중앙값을 끌어내리는 것**.

### 6.1.1. 결산 검증 방식과 결과 (2026-11-25)
- **평가 시점 고정(D8):** 사업연도마다 결산기말 30일 전(12월 결산이면 12월 1일). 그때 알 수 있던 것만 — 사업보고서 값은 결산기말+90일, 3분기 값은 3분기말+45일, 계획·컨센·회차는 공시일 이전.
- **표본:** `dart_alot` 2020~2025 사업연도, 실제 결산 몫 = 결산 공시 금액(없으면 연간 DPS − 3분기 누적 DPS). 튄 회차도 채점에 넣음(아래 — 대부분 실제 인상).
- **앞을 안 보는 채점:** 그 사업연도의 신호 순서는 그 전 해들로만 정함.

| 사업연도 | 직전 반복 (평균 오차·±20%) | 과거 적중순 |
|---|---|---|
| 2023·2024 | 25.6%·62% / 27.4%·55% | 같음(배울 해 부족 → 직전 반복이 뽑힘) |
| 2025 | 26.5%·55% (오차 중앙 16.7%) | **26.1%·57%** (오차 중앙 16.7%) |

평균 오차는 회차마다 100%에서 자름. 후보 금액은 직전 금액의 단위(5·10·50·100·500·1000원)로 반올림 — 회사는 딱 떨어지게 줌.

**데이터가 말해 준 것:**
- 이익이 줄면 배당은 **그대로**(중앙 1.00배, 깎는 회사 드묾), 3분기 누적 EPS가 작년보다 10% 넘게 늘면 결산 몫이 **13~33% 오름** — 해마다 같은 모양. → `earn_up`(직전 반복 × 과거 그런 회사들의 증가율, 사업연도 전 해들에서 배움).
- **성향×이익은 오차 30~40%** — 성향이 이익 따라 출렁여(117%·51%·186%) 직전 반복보다 훨씬 나쁨. 후보로만.
- **2배 넘게 뛴 회차는 대부분 실제 인상:** 6년 이력에서 그런 해 40번 중 26번은 다음 해도 유지. 뛴 금액 반복이 다음 해 오차 37% vs 뛰기 전 금액 63% → 직전 반복은 튄 회차도 그대로 씀. 추세·안 깎음만 튄 이력을 막음(이어 그리면 폭주).
- 정책(최소 DPS·목표 성향)은 2024~ 47회차뿐, 직전 반복과 다른 12회차에서 더 나빠 아직 뒤. 지주사는 **별도 기준 성향**이라 연결 EPS를 곱하면 크게 넘침 → 별도÷연결 순이익 비율로 보정.
- **12월 초 공개 데이터로는 오차 중앙 15~17%가 한계.** 금액을 정하는 정보(연간 실적·배당 결정)는 1~2월에 나옴.
- **컨센(M12)은 순서 밖, 사람 눈으로:** 과거 기록이 2026-11-20부터라 검증 전. 자가 점검이 예상과 컨센이 50% 넘게 다른 회차를 경고(`CONS_GAP`) — 2026-11-25 28건, 삼성전자(679 vs 4,086원)·GS(12,000 vs 3,000원) 등.

## 8. 현 코드와의 차이 (목표 대비) — 2026-11-25

`derive/dividend/amount.py` — 신호 7개, 순서는 `verify`가 과거 적중순으로(`med["priority"]`):
- `repeat_last`(M13) · `consensus_left`(M12) · `trend`(M7, 3년 안 줄었으면 평균 증가폭) · `payout_eps`(M7 성향 × 3분기 EPS×4/3) · `no_cut`(4년 넘게 안 깎은 회사, 작년 바닥) · `earn_up`(M7 이익 반영) · `policy`(M3 최소 DPS·목표 성향, 직전 반복 바닥)
- 결산 연간 신호는 연간 DPS를 추정해 **올해 이미 정한 배당(3분기 누적, 없으면 공시 회차)을 뺀다** = §5.3 배분 계산의 첫 단계
- 성향(`style`): 연간 DPS 3년 넘게 이어지고 안 줄었으면 안정, 줄었으면 연동, 짧으면 이력 짧음 — §3 네 유형 중 정책형·총환원율형·FCF형 판정은 아직
- 특별배당 가능성(M15 × M17) — `amount_special`, 화면 ⭐·엑셀 칸

**아직 없는 것:** 총환원율형(자사주 M9 수집) · 상한(M8) · 범위 출력(§5.4, D5) · 주주제안(M16)·매각(M14) · 컨센 검증(쌓이는 중, 결산 기록이 쌓이면 순서가 알아서 반영).
