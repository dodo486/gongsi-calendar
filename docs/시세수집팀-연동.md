# 공시캘린더 ↔ jhts 시세수집팀 연동

공시캘린더는 **시세를 직접 수집하지 않는다.** 네이버/wisereport 접속·파싱 코드는
전부 jhts 시세수집팀(`jhts.marketdata`)으로 옮겼고, 공시캘린더는 그걸 받아 쓴다.

```
jhts.marketdata (시세수집팀)                     공시캘린더
├─ store.py     일봉(candles)   ┐  로컬 미러      md_feed.py ─ 유일한 시세 창구
├─ feed.py      수급(flows)     ┘  (SISE_DB_PATH)   ├─ quotes.py         (shim)
├─ realtime/    현재값·지수·전시장·분봉(휘발)        ├─ market_universe.py(shim)
├─ reference.py 유동주식수                          ├─ earnings.py 시세부분(위임)
└─ source/naver.py  네이버 원천                     └─ consensus.py 시세부분(위임)
```

## 이관된 시세와 jhts 창구

| 시세 | jhts 창구 | 소스 |
|---|---|---|
| 현재값(현재가·등락률·거래대금·시총) | `md.quote(codes)` | realtime/quote |
| 현재/지수 등락률 | `md.stock_rate` / `md.index_rate` | realtime/quote |
| 전시장 스냅샷(전종목) | `md.market_snapshot` / `md.top_universe` | realtime/snapshot |
| 분봉 | `md.minute_closes` | realtime/intraday |
| 유동주식수 | `md.float_shares` | reference |
| 일별 OHLC | `md.candles`(미러) → `source.naver.daily_ohlc`(라이브) | store / naver |
| 일별 수급(외/기/개) | `md.flows`(미러) → `source.naver.investor_daily/trend`(라이브) | feed / naver |

- **실시간·분봉·참조**: jhts가 그때그때 소스에서 받는다(휘발성, 저장 안 함, 수초 캐시).
- **일별(OHLC·수급)**: 로컬 미러 우선 → 없으면 jhts 네이버 라이브. 미러는
  `sync_mirror.py`가 중앙 PG에서 채운다.

## 공시캘린더 쪽 변화 (시세 코드 삭제 → jhts 위임)

- `quotes.py` — 네이버/wisereport 스크래핑 **전부 삭제**, `md_feed` 위임 shim.
- `market_universe.py` — 전시장 스냅샷 스크래핑 삭제, shim.
- `earnings.py` — `naver_rate`/`naver_index_rate`/`naver_daily_map`/`minute_closes`
  본문을 jhts 위임으로 교체(이름·시그니처 유지 → monitor·kind_limits 무수정).
- `consensus.py` — `naver_prices`/`naver_trend`(일별 시세)를 jhts 위임으로 교체.
- `md_feed.py` — 공시캘린더의 유일한 시세 어댑터(모든 창구 매핑).

도메인 데이터(DART 공시·실적·배당·유증, KIND 거래정지·상하한, 뉴스, ETF구성)는
시세가 아니라 그대로 공시캘린더가 수집한다.

## 설치 (필수 — 시세는 이제 jhts 의존)

```bash
pip install "jhts-marketdata[postgres]"   # 또는: pip install "/Users/hyeyoung/jhts[postgres]"
```

- 미설치 시 `md_feed.AVAILABLE=False` → 시세 함수가 빈 값을 돌려주고 화면은
  시세만 빈 채로 뜬다(크래시 안 함). 시세를 보려면 설치가 필요하다.
- 읽기(런타임)만 하면 로컬 미러는 sqlite라 `postgres` extra 불필요. 동기화
  실행기(`sync_mirror.py`)만 psycopg2가 필요.

## 동기화 (중앙 PG → 로컬 미러) — 러너/회사 데탑에서

```bash
export SISE_DB_URL="postgresql://...supabase..."   # 중앙(소스)
export SISE_DB_PATH="$(pwd)/data/sise.db"          # 로컬 미러(대상)
python sync_mirror.py            # 전체 복제 (장 마감 후 cron 권장)
python sync_mirror.py --dry-run  # 행 수만 확인
```

## 주의 / 한계

- **미러 커버리지 = jhts가 수집한 종목뿐.** 없는 종목은 자동으로 네이버 라이브로
  폴백한다(공시캘린더는 그래도 스크래핑 코드가 없다 — 폴백도 jhts 안에서 일어남).
- **네이버 데스크톱 외국인 페이지(finance.naver frgn)가 개편돼 표가 사라졌다.**
  그래서 `investor_daily`는 표가 비면 m.stock trend로 폴백한다(외/기 순매수만,
  보유주수·보유율은 없음). 보유주수까지 필요하면 별도 소스 확보가 필요하다.
- 실시간 현재값의 부호/파싱 정본은 jhts `source/naver.py`가 소유(한 곳 정의).
